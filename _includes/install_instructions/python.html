Python

Python is a popular language for research computing, and great for general-purpose programming as well. Installing all of its research packages individually can be a bit difficult, so we recommend Conda-forge, an all-in-one installer.

Regardless of how you choose to install it, please install the most recent Python version available by going to the latest download site and scrolling to the Files section to find the download for your operating system.

Python Setup: Anaconda (Python)

Please finish these steps before our first Python class. If you encounter issues, please come early to the first day (8:00 AM) and we will help you troubleshoot. You will install Anaconda (Python plus many useful tools), create our class environment from the file Carpentries.yml, and open JupyterLab, where we will write all our code.

Set aside about 45 minutes and use a good internet connection. You do not need any programming experience. If anything goes wrong, take a screenshot of the whole window and send it to your instructor.

Before You Start

You need at least 5 GB of free disk space, an internet connection, and one of the computers below. You do not need administrator rights.

Your Computer What to Do
Windows 11 (most laptops) Follow this guide as written. Run Windows Update first.
Windows 10 The install still works, but Anaconda stopped releasing new packages for Windows 10 on June 30, 2026. Upgrade to Windows 11 if you can.
Windows on ARM (Snapdragon / "Copilot+" laptops) Anaconda does not support these. Contact your instructor before installing.
Mac with Apple chip (M1, M2, M3, M4…) Follow this guide as written. Needs macOS 12.1 or newer.
Mac with Intel chip The newest installer does not support Intel Macs. See the Intel Mac note in Step 1.
Linux (64-bit) Follow the Linux steps.
Chromebook or iPad Anaconda cannot be installed. Contact your instructor.

Not sure which Mac you have?
Click the Apple menu > About This Mac. If it says Chip: Apple M…, you have an Apple chip. If it says Processor: Intel, you have an Intel Mac.

Already have Anaconda installed?
You can keep it. Skip to Step 3 to check that it works.

Step 1: Download Anaconda

  1. Go to anaconda.com/download.
  2. The page asks for your email. You can skip this: click the Skip registration (or Skip to download) link under the button.
  3. Under Anaconda Distribution (not Miniconda), download the installer for your computer:
    • Windows: 64-Bit Graphical Installer (a .exe file)
    • Apple-chip Mac: Apple Silicon Graphical Installer (a .pkg file)
    • Linux: 64-Bit (x86) Installer (a .sh file)
  4. Wait for the download to finish. The file is large and lands in your Downloads folder.
    The current version is 2026.07-1, so the file name looks like Anaconda3-2026.07-1-Windows-x86_64.exe.

Intel Mac only:
Go to the Anaconda installer archive, and download the newest file whose name ends in MacOSX-x86_64.pkg. Anaconda stopped building new Intel Mac packages in August 2025.

Step 2: Install Anaconda

Follow the steps for your system only. Installing takes 5–15 minutes.

Windows

  1. Open your Downloads folder and double-click the .exe file.
  2. Click Next, then I Agree.
  3. Choose Just Me (recommended) and click Next.
  4. Check the install folder. Keep the default unless your Windows user name contains a space or non-English letters (for example C:\Users\Maria Lopez). In that case, change it to C:\anaconda.
  5. On the Advanced Options screen, keep the defaults. Do not tick "Add Anaconda3 to my PATH".
  6. Click Install, wait, then click Next and Finish.

Mac

  1. Open your Downloads folder and double-click the .pkg file.
  2. Click Continue through the screens, then Agree.
  3. If asked where to install, choose Install for me only.
  4. Click Install and enter your Mac password if asked.
  5. Wait for "The installation was completed successfully", then click Close.

Linux

  1. Open a terminal and run the installer (press Tab to complete the file name): 
    bash ~/Downloads/Anaconda3-2026.07-1-Linux-x86_64.sh
  2. Press Enter to scroll the license, then type yes.
  3. Press Enter to accept the default install location.
  4. When asked whether to initialize conda, type yes.
  5. Close the terminal and open a new one.

Step 3: Check That Anaconda Works

You will type commands into a text window. We call it the prompt in the rest of this guide.

  1. Open the prompt:
    • Windows: Click Start, type Anaconda Prompt, and open it. Do not use the normal Command Prompt or PowerShell.
    • Mac: Press Cmd + Space, type Terminal, and press Enter.
    • Linux: Open your terminal.
  2. Look at the start of the line. You should see (base).
  3. Type this and press Enter: 
    conda --version
    If you see something like conda 25.11.1, Anaconda works. If you see "not recognized" or "command not found", see Troubleshooting.

Step 4: Create the Class Environment

An environment is a separate box of Python tools set up exactly for our class. You only do this step once.

  1. Download Carpentries.yml from the link your instructor shared and save it in your Downloads folder.
    • If the file opens as text in your browser, go back, right-click the link, and choose Save link as.
    • On Windows, make sure the name ends in .yml, not .yml.txt.
  2. In the prompt, go to your Downloads folder: 
    cd Downloads
    (On Mac or Linux you can also type cd ~/Downloads.)
  3. Create the environment. Type the file name exactly, with a capital C: 
    conda env create -f Carpentries.yml
  4. You may be asked: Do you accept the Terms of Service (ToS)? Type a and press Enter. It may ask more than once, once per channel.
  5. Wait. This can take 5–20 minutes. It is finished when you see "To activate this environment, use conda activate carpentries".
  6. Switch into the new environment: 
    conda activate carpentries
    The start of the line should change from (base) to (carpentries).

Step 5: Open JupyterLab and Run a Test

  1. With (carpentries) showing in the prompt, type: 
    jupyter lab
  2. JupyterLab opens in your web browser after a few seconds. If it does not, copy the link starting with http://localhost:8888/lab?token= from the prompt into your browser.
  3. Keep the prompt window open. Closing it stops JupyterLab.
  4. In JupyterLab, click File > New > Notebook. If asked to pick a kernel, choose Python 3.
  5. Click in the grey box, type the line below, and press Shift + Enter: 
    print("Hello, Python!")
    If Hello, Python! appears under the box, you are ready for class.
  6. To finish, click File > Shut Down in JupyterLab, then close the prompt window.

Prefer clicking to typing?
Open Anaconda Navigator from your Start menu or Applications folder. On the Home tab, change Applications on from base to carpentries, then click Launch under JupyterLab. (Navigator can be slow to start.)

Every Class: Quick Start

Steps 1–4 are one-time setup. At the start of every class, do only this:

  1. Open the prompt (Anaconda Prompt on Windows, Terminal on Mac).
  2. Type these two commands, pressing Enter after each: 
    conda activate carpentries
jupyter lab
  3. Leave the prompt window open while you work.

JupyterLab starts in your home folder. Use the file browser on the left to make a folder called python-class and keep all your notebooks there.

Troubleshooting

What You See What to Do
'conda' is not recognized (Windows) You opened the normal Command Prompt or PowerShell. Open Anaconda Prompt from the Start menu instead.
conda: command not found (Mac) Close Terminal and open a new one. Still failing? Run /opt/anaconda3/bin/conda init zsh (or ~/anaconda3/bin/conda init zsh), then reopen Terminal.
No (base) at the start of the line Close the prompt and open a new one. On Windows, check you opened Anaconda Prompt.
EnvironmentFileNotFound or "file not found" You are not in the folder with the file, or it is named Carpentries.yml.txt. Type dir (Windows) or ls (Mac/Linux) to list the files, and rename it if needed.
CondaToSNonInteractiveError: Terms of Service have not been accepted Run the ToS acceptance commands in the code box below, then try Step 4 again.
prefix already exists The environment is already there. Skip to Step 5. To start fresh, run conda env remove -n carpentries, then repeat Step 4.
Stuck on "Solving environment" Wait up to 30 minutes on a good connection. If it is still stuck, press Ctrl + C and contact your instructor.
ModuleNotFoundError in a notebook You started JupyterLab from (base). Close it, run conda activate carpentries, then jupyter lab again.
Browser did not open Copy the http://localhost:8888/lab?token=… link from the prompt into your browser.
Windows install errors mentioning the path Your user name has a space or special characters. Reinstall and choose C:\anaconda as the folder.

Accept Terms of Service Manually

Run these commands if prompted for ToS issues (Windows users also run the third line):

conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/msys2

Still stuck? Send your instructor a screenshot of the whole prompt window, and say whether you use Windows, Mac, or Linux.
